# TCE Installer and Package Manager

This is the first public version of the TCE environment. This version may contain bugs that were not detected by the developer and/or testers.
To properly install TCE, you may need to run the installer as an administrator.
Windows defender may consider Titan as a threat, therefore c:\titan may need to be added to the folder as an exclusion.
TCE supports English language after installation. Some strings in the environment were auto translated for English speakers.
